# Project Noclip — Decisions

**Last updated:** 2026-08-03

## Locked for the Level 0 foundation

1. Browser-first client.
2. TypeScript + Vite.
3. PlayCanvas Engine in a repo-first npm workflow.
4. World core remains renderer-independent.
5. Vercel hosts the client only.
6. Nakama + PostgreSQL is the intended future connected backend.
7. Offline and Connected World characters are separate.
8. Level 0 is mostly empty and does not use routine combat.
9. Hounds are future rare breach events, disabled by default.
10. Facelings do not physically inhabit baseline Level 0.
11. Items are found; no universal complete starter kit.
12. Starter roll defaults to 15% none, 60% one, 25% two.
13. Item instances are trade-ready from the first schema.
14. World generation, loot, starter rolls, and exits use seeded randomness.
15. Geometry is regenerated; only deltas are saved.
16. Marker drawings are limited vector strokes.
17. World Day and Exposure Day are separate.
18. Exposure in unstable space is traversal-driven.
19. Exposure in stable space is time-driven.
20. Manila Room is the primary Level 0 rendezvous.
21. Not every Level 0 exit leads to Level 1.
22. World Lab is a first-class development feature.
23. Original assets and prose are preferred.
24. Tests are written or updated as deterministic systems are implemented, not postponed until release.
25. Every iteration ends by updating `CURRENT_STATE.md`, reviewing `VISION.md`, and rewriting `MASTER_BUILD_PROMPT.md` for the next iteration.
