# Audits

Store complete independent test and release-readiness reports here using dated names such as:

```text
2026-08-04-level-0-browser-audit.md
```

Use the audit template from `xash-mind/project-operations/templates/AUDIT.template.md` and the shared testing playbook.

Audits should distinguish Passed, Failed, Not Implemented, and Untested behaviour; include exact commit/deployment evidence; assess first-time-user UX and accessibility; and link confirmed findings to GitHub Issues.

Do not use this folder as an unstructured activity log. The compact accepted state belongs in `STATUS.md`.
