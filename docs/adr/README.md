# Architecture Decision Records

Use this folder for durable technical decisions that future agents could otherwise accidentally reverse.

Create numbered files such as:

```text
0001-renderer-independent-world-state.md
0002-save-schema-versioning.md
```

Use the ADR template from `xash-mind/project-operations/templates/ADR.template.md`.

An ADR is appropriate when choosing or changing architecture, persistence contracts, authority boundaries, generation rules, renderer strategy, deployment design, or another decision with meaningful alternatives and long-term consequences.

Ordinary implementation details and temporary debugging notes belong in Issues or Pull Requests instead.
